# TR Tools hub surface brief

Mode: Persuade. Audience: TR employees (site is public on GitHub Pages) arriving to pick one small tool and open it. Action: open Planner or Race The Coco from the hub. The hub has its own bold identity, separate from the tools; it must handle a handful (3 to 6) of tools over time. Previews are drawn miniatures built in HTML/CSS (no screenshots, no live embeds). Switching folders slides the chosen folder forward. All data stays in each person's browser.

Unresolved: none.

## Direction contract

THESIS: The hub is a drawer of manila folders, one per tool. It refuses the equal grid of icon cards and shows the tool you pick at full size instead.

OWN-WORLD: Desk-kraft ground (#cdbf9f), manila tabs (#d9b96a), cream folder paper (#fbf6e9), ink #2b2b2b, one rubber-stamp red (#b5342a) reserved for the Open action. Typewriter lettering (Special Elite) for the brand, tabs and tool names, system sans for body. Heavy 3px ink outlines, flat paper with depth only from overlapping folders.

STORY: A coworker lands, sees the drawer, pulls up the folder they want, recognises the tool from its miniature, and stamps Open.

FIRST VIEWPORT: Brand "TR Tools" and one-line tagline top left over the desk. Directly below, a row of staggered tabs (Planner, Race The Coco) atop the open folder. The folder shows the tool name and description on the left with a red OPEN stamp link, and a drawn miniature of the tool on the right. The inactive folder peeks above the front one.

FORM: Folder Tabs, my own top grounded pick (kind: pick), seed:9095a2111a47518b. Signature interaction: choosing a tab slides that folder forward over the other.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
